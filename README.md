# ShotPro — firmwares caméra

Ce dépôt sert uniquement à distribuer les firmwares de la caméra à
l'application ShotPro, via ses **Releases**. Le code n'est pas ici.

- **Tag** d'une release = version exacte affichée par la caméra après la mise à jour.
- **Fichiers** = les `.bin` du constructeur, non renommés (`FWQ8L.bin` pour la
  Q8L, `FWQ8_8.bin` pour la Q8L PRO).
- **Pre-release** = visible uniquement par les builds de test de l'app.
